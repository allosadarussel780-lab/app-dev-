# 🎬 Rampage (2018)
## My Favorite Movie
**Rampage** is my favorite movie because of its *non-stop action* and ~~boring~~ exciting giant-monster battles.
> "Big creatures, bigger action." – my own summary of the movie

3. Jeffrey Dean Morgan as Agent Harvey Russell
4. Malin Åkerman as Claire Wyden
## Story Summary
A primatologist named Davis Okoye shares a close bond with George, an intelligent albino gorilla. When a genetic experiment goes wrong, George and other animals grow to enormous size and become aggressive. Davis must work to save George and stop the destruction.
## Why I Like It
- Exciting action scenes
 - Giant gorilla, wolf, and crocodile
 - City-wide destruction
- Friendship between a human and an animal
- Fun and easy to watch
